# Jai Prasanna Sai Portfolio

Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Preview on your laptop
1. Download and extract this ZIP.
2. Open the extracted folder.
3. Double-click `index.html` to open it in your browser.

## Publish on GitHub Pages
1. Create a new **public** GitHub repository (e.g. `jai-prasanna-portfolio`).
2. Upload the *contents* of this folder to the repository root. Include `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then Save.
5. Wait for deployment. The URL normally looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes
- Resume and certificates are public when deployed. Publish only if you're comfortable sharing them.
- Project links currently point to your GitHub profile. Replace them with the specific project repository URLs when available.
- Review all project descriptions before publishing to ensure they accurately describe work you can demonstrate.
